# ZARA 与优衣库：第二阶段初稿写作安排

**本周目标：在第一阶段资料基础上，完成一篇结构完整、论点连贯、可以进入修改阶段的英文报告初稿。**

本轮周期为 **2026年11月2日至11月8日**，所有截止时间均为北京时间。正式提交日期为 **11月13日**；本周完成初稿，随后留出时间修改与定稿。

## 一、本周写作方向

以中国大陆市场为主，比较优衣库与 ZARA 的竞争定位、营销策略和顾客参与，并为其中一个品牌提出提升竞争优势的建议。

建议围绕这一主线展开：**两品牌都提供功能、设计和体验价值，但强调的消费者利益不同；文章需要分析这些差异如何通过营销策略和顾客互动形成竞争优势，以及哪些地方仍有改进空间。** 建议对象暂沿用第一阶段的优衣库，由全组在写作开始时统一。

本周以已有材料为基础直接写作。仅在关键论点缺少支持时补查资料，阅读笔记和案例整理服务于正文，不另设台账或阅读卡的补交任务。

## 二、章节与四人分工

正文以 **2,000英文词**为目标，允许±10%。以下为建议分配，整合时可调整。

| 负责人 | 负责内容 | 建议词数 | 本周交付 |
|---|---|---:|---|
| A：竞争定位与统筹 | 摘要150词、引言100词、竞争定位400词、结论100词 | 750 | 完成本人章节，选用定位图，整合四人内容形成全文初稿 |
| B：营销策略 | 比较产品、价格、渠道与促销中最有解释力的2—3项差异，说明其如何支持定位 | 450 | 营销策略章节及所用参考文献 |
| C：顾客参与 | 比较两品牌社交媒体、门店体验或服务中的参与方式，评价其价值与局限 | 350 | 顾客参与章节及所用参考文献 |
| D：竞争优势与建议 | 综合前文判断，提出一个重点建议，说明理由、实施思路、可行性与局限 | 450 | 建议章节、更新后的参考文献总表及全文审阅意见 |
| **合计** | **一篇完整报告** | **2,000** | **周末形成审阅并修改过的初稿** |

A 负责把定位与后续章节连接起来，摘要和结论在整合正文后完成。B、C、D 写作时直接比较两品牌，避免分别写成两份品牌介绍。D 的建议应回应前文分析，并说明相对于品牌现有做法的改进。

## 三、一周协作循环

**周内写作 → 周五交稿并整合 → 周末审阅与修改 → 周日形成完整初稿。** 每人自行安排周内工作，不设置逐日任务。

| 本周节点 | 截止时间 | 交付要求 |
|---|---|---|
| 分章写作与首次整合 | **11月6日（周五）24:00前，即11月7日00:00前** | 四人提交本人章节及引用来源；A 汇总为可通读的合并稿。各作者提前与 A 衔接交稿，给整合留出时间 |
| 全文审阅与初稿完成 | **11月8日（周日）24:00前，即11月9日00:00前** | D 审阅全文并提出重点修改意见；各作者配合修改，A 更新合并稿，全组通读确认 |

周末主要解决论点不一致、内容重复、比较不足、建议脱离分析和引用缺失等影响文章质量的问题。D 的审阅随材料到位开展，及时反馈，给作者留下修改时间。

## 四、什么样的初稿算完成

- **内容完整：**摘要、引言、竞争定位、营销策略、顾客参与、建议和结论均有实际正文，没有空白章节或仅有提纲。
- **分析有分量：**用理论解释案例，比较两品牌的优势、取舍与局限；关键判断有来源支持，并考虑反例，避免只介绍品牌做了什么。
- **引用可用：**至少10篇相关学术文献实际用于正文，附上对应参考文献；品牌官网、年报和新闻作为事实来源另列。无法核实的数字删除或改写，不能用理论代替品牌事实。
- **可以继续修改：**全文接近目标字数、基本术语与引用格式统一，仍有疑问的位置直接批注，便于下一轮处理。

具体写作时，B 优先处理现有材料中尚未核实的 SKU、生命周期、折扣和渠道比较；C 从已上传论文与现有案例中提炼参与分析；A、D 统一定位判断与建议依据，注意区分品牌主张、单店案例与实际效果。

课程格式要求沿用作业说明：Times New Roman 12pt、1.5倍行距、两端对齐；图表编号并注明来源，引用按课程指定指南统一。封面、目录、参考文献和附录不计入正文词数，附录最多两页。正式定稿前再统一完成版式检查。
