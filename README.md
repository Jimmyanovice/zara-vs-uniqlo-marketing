# ZARA vs UNIQLO：第一周计划与分工

第一周安排为 **2026年10月20日（周二）至10月25日（周日）**。这一周的目标是：**把资料找齐、把两家品牌放在同一框架下比较，并确定报告准备论证什么。**

你们还没提供组员人数，下面先按 **4人小组，分别用A、B、C、D代称**安排。每个人都研究ZARA和优衣库，按分析主题分工，方便后续直接写成对比报告。

### 每周大任务截止时间

| 负责人 | 每周大任务 | 统一截止时间（北京时间） |
| --- | --- | --- |
| A、B、C | 完成并上传各自本周负责的完整材料或章节；A同时整理供D审查的总提纲或合并稿 | 每周五24:00前，即周六00:00前 |
| D | 完成本周负责的材料、整体审查、反馈及复核记录 | 每周日24:00前，即周一00:00前 |

**只设置以上两个人员组别的大任务DDL。** 文献、阅读卡、证据表、分析提纲等均属于各自大任务的交付内容，不单独设置小DDL。周末A、B、C按D的反馈配合修改，D在自己的大任务截止前完成审查与复核。

第一周对应：A、B、C在 **2026年10月23日24:00前（10月24日00:00前）** 完成；D在 **2026年10月25日24:00前（10月26日00:00前）** 完成。

### 二、每个人具体负责什么、上传什么

#### A：研究范围、竞争定位与进度统筹

**负责回答：两家品牌分别服务谁，消费者为什么选择它们？**

具体任务：

1. 组织大家确定比较范围。建议先考虑中国市场，资料时间范围由全组统一。
2. 查找STP、品牌定位或感知价值相关文献。
3. 收集两家品牌关于目标消费者、品牌主张、核心产品价值的证据。
4. 提出定位图的两个比较维度，并解释选择原因。
5. 维护总提纲、检查各人的资料是否齐全。

**本周需要上传：**

| 材料 | 内容要求 |
| --- | --- |
| 《研究范围与任务分工》 | 市场、时间范围、研究问题、负责人、内部截止日期，约1页 |
| 3篇学术文献及阅读卡 | 主题围绕STP、定位、感知价值；提交全文或可访问链接 |
| 定位证据与分析提纲 | 至少4条证据，两家各2条；3个初步判断；定位图草稿及依据 |
| 《报告总提纲》 | 整合全组主题、核心观点、章节和字数安排 |

定位图可以先画草稿，但坐标与品牌位置必须说明依据；如果没有消费者调查，应标明它是基于现有资料形成的分析判断。

#### B：营销策略比较

**负责回答：两家品牌如何通过产品、价格、渠道和促销支持自己的定位？**

具体任务：

1. 查找营销组合、零售营销或全渠道相关学术文献。
2. 用4Ps整理两家品牌的证据。
3. 选出最值得写进报告的2—3个差异，不必平均铺开四个方面。
4. 分析这些差异如何影响品牌竞争力，以及可能有什么局限。

**本周需要上传：**

| 材料 | 内容要求 |
| --- | --- |
| 3篇学术文献及阅读卡 | 围绕营销组合、零售策略、渠道或价格策略 |
| 《4Ps品牌对比表》 | 四个维度均有初步资料；至少4条可引用证据，两家各2条；注明来源和日期 |
| 《营销策略分析提纲》 | 3个初步判断，每个附证据、理论解释及局限；列出仍缺的材料 |

价格比较应尽量选择**相同市场、相近品类、同一时期**的产品，并区分原价和促销价。

#### C：顾客参与与品牌关系

**负责回答：两家品牌如何吸引顾客互动，并维持持续关系？**

具体任务：

1. 查找顾客参与、品牌社群、忠诚度或顾客旅程相关文献。
2. 收集两家品牌在社交媒体、会员体系、App、门店或线上线下体验方面的案例。
3. 选择两家都能找到证据的维度进行比较。
4. 区分“品牌做了什么”和“是否产生效果”。

**本周需要上传：**

| 材料 | 内容要求 |
| --- | --- |
| 3篇学术文献及阅读卡 | 围绕顾客参与、品牌关系或忠诚度 |
| 《顾客参与案例表》 | 至少4条案例证据，两家各2条；包含活动或机制、渠道、日期、来源；适当保留截图 |
| 《顾客参与分析提纲》 | 3个初步判断，说明参与方式、可能效果、证据局限，以及值得改进之处 |

例如，点赞和评论可以支持互动层面的分析；如果没有销售或复购数据，就不能据此直接断言提升了销售或忠诚度。

#### D：最终审查负责人，兼顾竞争优势与建议分析

**负责回答：现有策略有哪些不足，最终应该为哪家品牌提出什么改进？**

具体任务：

1. 查找差异化、竞争优势、品牌战略等相关学术文献。
2. 收集两家品牌面临的营销问题或竞争压力证据。
3. 阅读A、B、C上传的对比材料，找出“问题—证据—改进方向”的联系。
4. 提出3个候选建议方向，并比较它们的可行性。
5. 建立参考文献总表，检查重复和缺失信息。

**本周需要上传：**

| 材料 | 内容要求 |
| --- | --- |
| 3篇学术文献及阅读卡 | 围绕竞争优势、差异化或品牌战略 |
| 《品牌问题证据表》 | 至少4条证据，两家各2条；说明问题、来源及可能影响 |
| 《建议方向与对象选择》 | 3个候选建议；分别注明对应问题、依据、实施难点；推荐一个建议对象 |
| 《参考文献总表》 | 汇总12篇文献，核查作者、年份、题名、期刊、DOI或链接及重复情况 |

D负责整篇报告的最终审查，并汇总参考文献。研究阶段保留上述竞争优势与建议分析任务；第一周先检查提纲和资料缺口，完整合并稿形成后进行最终审查。

最终审查包括：对照作业要求与评分标准检查内容覆盖，核对论点与证据、两品牌比较口径、建议依据、引用与参考文献、字数和排版格式。D将问题列入《审查问题清单》，标注位置、修改要求和负责人；对应作者修改后，由D复核并记录结果。清单与复核记录保存在04_报告草稿。

**各成员负责自己提供的资料和所写章节，并完成审查后的修改；D负责审查与复核。** 合并稿、修改及复核纳入上述每周大任务安排，不再设置独立的小DDL。D复核通过后，由全组确认定稿，再交指定提交人提交。

### 三、每周如何推进

A、B、C自行安排检索、阅读、证据收集和分析写作，在周五大任务截止前提交本周完整成果。A整理供D审查的总提纲或合并稿。

D可在周内提前阅读已有材料，周末集中检查完整成果，列出问题并与对应作者沟通修改，在周日大任务截止前完成自己的研究材料、审查和复核记录。第一周审查对象为资料、分析提纲和总提纲；正文形成后审查完整报告。

各成员可以自行安排过程中的工作顺序，项目不为每一步另设截止时间。
