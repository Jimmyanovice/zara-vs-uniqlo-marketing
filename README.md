# ZARA 与优衣库小组报告：第二阶段写作安排

**阶段目标：**在第一阶段资料基础上，完成一篇论点明确、理论与案例结合、具有批判评价和可执行建议的正式报告。第二阶段不以堆资料或逐条补齐台账为目标；每位成员围绕共同论点贡献必要的分析，最终形成一篇连贯的文章。

**最终提交：2026年11月13日。**课程具体提交时刻以课程平台为准。按北京时间安排，2026年11月3日至12日为最后十天工作窗口，11月12日完成可提交定稿，11月13日仅留作按课程要求上传及检查回执。

## 一、报告目标与共同论点

报告题目可暂定为 **“优衣库与 ZARA 在中国服装市场的竞争定位、营销策略与顾客参与”**。写作时回答三个问题：

1. 两个品牌如何以不同的价值重点吸引消费者，又在哪些方面存在重叠？
2. 产品、价格、渠道、传播和顾客接触如何支持各自定位？现有资料能说明哪些机制，不能证明哪些结果？
3. 哪个品牌有更清楚、可行且有证据支持的改进空间？建议如何实施并判断是否有效？

**建议采用的中心论点（全组在11月3日确认）：**优衣库与 ZARA 并非“功能”与“时尚”的绝对对立；两者都提供日常与表达价值，但其产品组合、传播和体验所强调的利益不同。竞争优势取决于这些活动能否彼此配合并回应中国市场需求。报告比较两种价值实现方式，并基于现有证据为优衣库提出一个范围明确、可测试的改进建议；不把单店案例、品牌自述或单一财年表现写成消费者结果或因果证明。

如全组讨论后选择不同建议对象，应同步调整中心论点、章节和建议依据，不要在正文里保留互相冲突的推荐。

## 二、目标结构与字数

课程要求正文 **2,000词，允许±10%**；封面、目录、参考文献和附录不计入。建议以约2,000英文词为目标，预留整合空间。摘要、图表标题等是否计入，按课程平台口径处理；不得靠长图注或附录变相扩充正文。附录最多两页。

| 章节 | 建议词数 | 主责 | 写作目的 |
|---|---:|---|---|
| Executive summary | 150 | A 起草，全组确认 | 简述比较对象、主要判断、核心建议和关键限制 |
| Introduction and analytical framework | 350 | A | 说明研究问题、范围和分析框架；简要引入 STP、品牌定位与感知价值 |
| Comparative positioning and marketing strategy | 450 | B，A 提供定位衔接 | 比较两品牌的产品、价格、渠道、传播，集中分析最有解释力的差异 |
| Customer engagement and brand relationship | 350 | C | 比较顾客接触和参与机制，区分品牌提供的活动、实际参与及可观察结果 |
| Competitive advantage and recommendation | 500 | D | 评价优势、局限和替代解释，提出一个优先建议、实施步骤、指标与风险 |
| Conclusion | 200 | A 起草，D 复核 | 回答研究问题，收束比较与建议，不引入新证据 |
| **合计** | **2,000** | 全组 | 以上为工作预算，合并时可在±10%范围内调整 |

理论不应集中成脱离案例的长篇定义。优先把理论放在解释证据和比较结论的位置，并使用至少10篇相关学术来源；官网、年报、新闻和行业报告用于品牌事实，不能代替学术文献数量。

## 三、成员任务

### A：总论点、定位与整合

- 11月3日主持确定中心论点、报告标题、比较范围和建议对象，并维护本 README 中的共识。
- 基于现有定位图和说明撰写引言与定位分析，保留“定性研究者判断”的限定；不要把图上位置写成消费者调查结果。
- 统筹约2,000词结构，起草摘要和结论，检查各节是否围绕同一问题推进、是否重复。
- 汇总最终文档版本；逐项确认封面成员姓名、学号、字数及图表编号和来源。

### B：营销策略比较

- 撰写约450词的4Ps比较，选择最能解释竞争差异的2—3个方面深入讨论，不必平均铺陈四个P。
- 先复核现有证据表里的 SKU 占比、产品生命周期、折扣幅度和全渠道结论：找到直接、可定位的原文和适用市场/时间后再引用；无法核实的精确数字删除或改成有来源支持的谨慎表述。
- 把南京旗舰店的线上查询、店取等材料作为对“ZARA渠道整合较弱”这一笼统判断的反例，讨论服务覆盖边界。
- 将每一项比较连接到理论解释、消费者价值和证据限制；避免把文献中的一般结论写成两品牌已经实现的效果。

### C：顾客参与与品牌关系

- 阅读已上传的三篇论文，提交每篇简明阅读卡：完整书目信息、核心概念/发现、对本题的用处、适用限制。优先选出与中国服装零售或社交媒体参与最相关的研究。
- 从 A、D 已有材料中挑选两品牌可比较的互动/体验案例，至少各选两个有原始来源、明确日期和市场范围的案例；可使用优衣库活动/服务与 ZARA 南京旗舰体验等现有资料。
- 撰写约350词：说明品牌提供了什么参与触点、消费者可能如何参与、现有材料实际能证明到哪一层。没有转化、满意度或复购数据时，不宣称活动提高销售或忠诚度。
- 将案例表作为写作底稿即可，正文只保留支撑论点的例子，不把完整台账塞进附录。

### D：竞争优势、建议与最终内容审阅

- 从已有问题证据和文献中选出最有解释力的竞争压力，纳入 FY2026 优衣库中国大陆业绩改善这一反证，避免把 FY2025 下滑描述为当前持续下滑。
- 撰写约500词的建议章节。优先评估“按地区气候与生活场景改善现有商品内容和导购衔接”的方案；说明它解决什么问题、如何小范围试行、用什么指标判断、何时调整或停止。
- 提出建议时说明已存在的相关服务/活动，避免把已有做法包装成全新能力；写清资源、执行限制与可能副作用。
- 审阅合并稿的论点、证据准确性、品牌/市场/年份口径、建议可行性、文内引用与参考文献对应关系，并提交具体修改意见；复核作者修改结果。报告形成后完成的审阅记录存入 `04_报告草稿/`。

## 五、统一写作与审阅标准

- 每节先提出一个可回答的判断，再用理论解释、两品牌比较和案例材料支撑，最后交代限制或反例；避免按资料来源逐条罗列。
- 关键比较尽量保持中国大陆、相近时间和相似使用场景。集团数据、全球品牌主张、单店案例、财年与自然年须明确标注，不能互相替代。
- 品牌官网和管理层材料可证明品牌“发布/提供/声称”了什么；除非有消费者或经营结果数据，不延伸成消费者认知、忠诚度、市场份额或因果成效。
- 用一个建议建立清楚的问题—措施—执行—评价逻辑。指标可包括购买转化、毛利/净贡献、退货、缺货或服务完成情况；若没有基线和试点数据，明确写成待检验方案，不编造提升幅度。
- 至少10篇学术来源必须与正文论证相关并实际在文中引用。现有19条候选文献不自动等于19篇合格引用；按参考文献总表里的待核项处理书目信息、文献类型和未核读结论。
- 图表须有编号、标题/说明和来源。定位图注明为定性示意，距离和坐标不代表测量值。完整证据库作为研究底稿，不作为附录打印；附录总计不超过两页。
- 封面包括题目、全体成员姓名、学号和正文词数。正文按 Times New Roman 12pt、1.5倍行距、两端对齐；引用格式按课程指定 Harvard/APA 7 指南统一。
- 当前课程规范文档保留了多个 GenAI 等级选项，未见明确勾选最终适用等级。正式使用生成式 AI 起草或改写任何受评正文前，由全组向课程负责人确认允许范围和披露要求；如不允许，应由成员自行撰写受评内容。本计划是项目管理安排，不替代课程的学术诚信要求。
