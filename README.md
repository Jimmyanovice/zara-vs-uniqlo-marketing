本轮周期为 **2026年11月2日至11月8日**，所有截止时间均为北京时间。正式提交日期为 **11月13日**；本周完成初稿，随后留出时间修改与定稿。

## 一、以作业原题为核心

作业要求：完成一份小组报告，分析同一行业中两个竞争品牌的竞争定位，评价两者的营销策略与顾客参与，并为其中一个品牌提出提升竞争优势的建议。

本报告选择服装行业的优衣库与 ZARA，以中国大陆市场为主要分析范围。全文围绕以下四项任务展开：

| 核心任务 | 正文需要回答的问题 | 主责 |
|---|---|---|
| **分析竞争定位** | 两品牌面向哪些需求与消费者？分别提供什么价值？它们的竞争差异与重叠是什么？ | A |
| **评价营销策略** | 两品牌如何通过产品、价格、渠道与促销支持定位？这些策略有哪些优势、取舍与不足？ | B |
| **评价顾客参与** | 两品牌怎样吸引互动、提供体验并维持关系？这些方式有哪些价值、局限与改进空间？ | C |
| **提出竞争优势改进建议** | 选择一个品牌，针对前文识别的问题提出哪些可行改进？为什么能增强其相对竞争力？ | D |

**文章的重点是比较与评价。**各节既要说明品牌采用了什么做法，也要解释其作用、优势和不足。建议对象可暂以优衣库为候选，最终根据前文分析确定；建议可包含若干相互配合的措施，并说明实施可行性及预期如何提升竞争优势。

第一阶段的定位图、文献和案例用于支持上述任务。写作中形成并修正核心论点，避免预先把“优衣库重功能、ZARA重时尚”当作全文结论。本周直接推进正文，仅在关键论点缺少支持时补查资料，阅读笔记和案例整理服务于写作，不另设台账或阅读卡的补交任务。

正文以 **2,000英文词**为目标，允许±10%。以下为建议分配，整合时可调整。

|---|---|---:|---|
| A：竞争定位与统筹 | 摘要150词、引言100词、竞争定位400词、结论100词 | 750 | 完成本人章节，选用定位图，整合四人内容形成全文初稿 |
| B：营销策略 | 评价两品牌营销策略，重点讨论2—3项关键差异及其优势、取舍与不足 | 450 | 营销策略章节及所用参考文献 |
| C：顾客参与 | 比较两品牌社交媒体、门店体验或服务中的参与方式，评价其价值与局限 | 350 | 顾客参与章节及所用参考文献 |
| D：竞争优势与建议 | 选择一个品牌，基于前文比较提出重点改进方向及配套建议，说明如何增强竞争优势 | 450 | 建议章节、更新后的参考文献总表及全文审阅意见 |

A 负责把定位与后续章节连接起来，摘要和结论在整合正文后完成。B、C、D 写作时直接比较两品牌，避免分别写成两份品牌介绍。D 的建议应回应前文分析，说明相对于现有做法的改进，以及它怎样增强所选品牌的竞争优势。

## 四、什么样的初稿算完成

- **紧扣原题：**明确完成两品牌竞争定位分析、营销策略评价、顾客参与评价，以及针对一个品牌的竞争优势改进建议。
- **内容完整：**摘要、引言、竞争定位、营销策略、顾客参与、建议和结论均有实际正文，没有空白章节或仅有提纲。
- **分析有分量：**用理论解释案例，比较两品牌的优势、取舍与局限；关键判断有来源支持，并考虑反例，避免只介绍品牌做了什么。
- **引用可用：**至少10篇相关学术文献实际用于正文，附上对应参考文献；品牌官网、年报和新闻作为事实来源另列。无法核实的数字删除或改写，不能用理论代替品牌事实。
- **可以继续修改：**全文接近目标字数、基本术语与引用格式统一，仍有疑问的位置直接批注，便于下一轮处理。

具体写作时，B 优先处理现有材料中尚未核实的 SKU、生命周期、折扣和渠道比较；C 从已上传论文与现有案例中提炼参与分析；A、D 统一定位判断与建议依据，注意区分品牌主张、单店案例与实际效果。

课程格式要求沿用作业说明：Times New Roman 12pt、1.5倍行距、两端对齐；图表编号并注明来源，引用按课程指定指南统一。封面、目录、参考文献和附录不计入正文词数，附录最多两页。正式定稿前再统一完成版式检查。
