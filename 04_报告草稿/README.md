# 报告草稿

本文件夹用于保存全组整合、讨论和修改中的报告文件，包括总提纲、章节草稿、合并稿及参考文献总表。

请存放：

- 报告总提纲：核心论点、章节结构、重点证据和字数分配，由A统筹。
- 各成员负责章节的正文草稿。
- 全组合并稿、修改意见和修订记录。
- 参考文献总表，由D汇总并检查重复及缺失信息。

每位成员负责核实自己提供的事实和引用。合并前统一引用格式，检查两品牌资料的市场、时间和比较口径是否一致。

建议命名：报告总提纲_日期.md、B_营销策略正文_v01.docx、报告合并稿_v01_日期.docx。更新时写清版本与日期，尽量避免多人同时修改同一文件。

经全组确认的最终提交文件放入05_最终提交。

## D负责最终审查

合并稿形成后，D逐项检查：

1. 内容是否覆盖作业要求与评分标准，结构和字数是否符合要求。
2. 论点是否清楚，章节是否重复或相互矛盾。
3. 两品牌的市场、时间和品类是否可比，结论是否有证据支持。
4. 建议是否回应已识别的问题，是否说明依据和可行性。
5. 正文引用、参考文献及图表来源是否完整一致。
6. 语言、标题、排版及文件格式是否统一。

D在本目录维护《审查问题清单》，记录问题位置、修改要求、负责人及处理状态。对应作者修改后，D逐项复核并留下记录；通过后由全组确认，再将定稿放入05_最终提交。
