# 作业要求与分工

本文件夹用于保存作业要求和小组协作安排，作为全组确认研究范围、任务与进度的依据。

建议存放：

- 老师提供的作业说明、评分标准和提交要求。
- 研究范围说明：比较市场、资料时间范围、目标消费者和研究问题。
- 组员名单、A—D角色对应关系、任务分工和内部截止日期。
- 会议记录、已确认的决定和待解决事项。

A负责统筹维护，其他成员及时补充自己负责的进展。项目根目录的README.md包含第一周计划；具体作业要求以老师发布的材料为准。

## 最终审查分工

D负责整篇报告的最终审查。A统筹研究范围、分工与进度，其他成员完成各自研究和章节。合并稿、作者修改与D复核纳入每周大任务，不另设小DDL。

流程：各成员交稿 → 形成合并稿 → D列出审查问题 → 对应作者修改 → D复核 → 全组确认定稿 → 指定提交人提交。

## 每周大任务DDL

A、B、C每周五24:00前（周六00:00前）完成并上传各自本周的完整成果；D每周日24:00前（周一00:00前）完成自己的材料和整体审查、反馈及复核记录。均为北京时间。

本目录内的各项材料属于对应成员的大任务，不另设子任务DDL。A、B、C在周末配合D处理审查意见。
