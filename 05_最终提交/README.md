# 最终提交

本文件夹用于保存经D最终审查并由全组确认、准备正式提交的最终版本，方便统一查找和提交。

根据老师的实际要求存放：

- 最终报告的Word和／或PDF版本。
- 需要随报告提交的附录、参考文献或其他附件。
- 封面、组员信息及分工声明（如作业要求提供）。
- 提交确认或回执（如有）。

放入前请确认：文件能够正常打开，字数与格式符合要求，引用和参考文献一致，组员信息完整，且已清理批注与修订痕迹。

建议命名：Group5_ZARA_vs_UNIQLO_Final_日期.pdf；实际命名和文件格式以老师要求为准。修改中的版本请保存在04_报告草稿，正式提交前由全组确认最终文件。

## 放入定稿的条件

D负责最终审查，确认审查问题已由对应作者修改并复核完成。全组确认文件后，再放入本目录。审查问题清单与复核记录保存在04_报告草稿。

D负责审查与复核，具体提交人由小组指定。最终文件如有影响内容或引用的修改，应再次交D复核后确认。
