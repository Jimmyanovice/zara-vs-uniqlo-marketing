# 品牌证据与截图

本文件夹用于保存ZARA与优衣库的事实资料、数据、案例、对比表及原始截图，为报告中的分析提供可追溯的证据。

A—D按各自主题上传：

- A：目标消费者、品牌主张、核心产品价值与定位证据。
- B：产品、价格、渠道和促销证据，以及4Ps品牌对比表。
- C：社交媒体、会员体系、App、门店体验等案例与顾客参与案例表。
- D：营销问题、竞争压力证据与品牌问题证据表。

按现有第一周计划，每人至少4条有效证据，两家品牌各至少2条；全组目标为至少16条。

每条证据请记录：品牌、主题、事实或数据、适用市场与时间、来源链接、资料发布日期、访问日期、PDF页码（如适用），以及能够支持的观点。截图需附来源链接和截取日期。

价格比较尽量使用相同市场、相近品类和同一时期的资料，并区分原价与促销价。建议文件名包含品牌、主题、日期和上传人，便于查找。
