# D：竞争优势文献

由D负责整理差异化、竞争优势和品牌战略等相关学术文献，为诊断两品牌的问题、评估改进建议提供理论依据。

请存放：

- 至少3篇相关文献的全文PDF或访问链接。
- 每篇文献对应的阅读卡，说明主要理论、可解释的竞争优势或问题、适用章节和局限。
- 关于建议可行性及战略取舍的理论笔记。

品牌问题证据放入02_品牌证据与截图；候选建议及建议对象选择放入03_个人分析提纲。D另负责汇总全组参考文献，参考文献总表放入04_报告草稿。文献引用与阅读卡格式见上一级README.md。

## D的主要协作职责：最终审查

D负责整篇报告的最终审查，本目录的文献整理是研究阶段的支持工作。合并稿形成后，D检查作业要求覆盖、论点与证据、品牌比较口径、建议依据、引用和格式。

D将问题交由对应章节作者修改，再逐项复核。审查问题清单和复核记录放入04_报告草稿；审查通过后，由全组确认定稿。
