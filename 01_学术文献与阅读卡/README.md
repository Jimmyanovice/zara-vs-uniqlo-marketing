# 学术文献与阅读卡

本文件夹用于整理报告引用的学术文献及阅读笔记，请按研究主题放入对应子文件夹。

| 子文件夹 | 研究主题 | 对应角色 |
| --- | --- | --- |
| A_竞争定位 | STP、品牌定位、感知价值 | A |
| B_营销策略 | 营销组合、零售营销、全渠道、价格策略 | B |
| C_顾客参与 | 顾客参与、品牌社群、忠诚度、顾客旅程 | C |
| D_竞争优势 | 差异化、竞争优势、品牌战略 | D |

按现有第一周计划，每人整理3篇相关学术文献及阅读卡，全组目标为至少12篇，登记后先检查是否重复。

每篇阅读卡约150—250字，包含：完整参考文献和DOI或访问链接、主要理论或发现、对两品牌比较的帮助、适用章节、研究局限。直接引文需注明页码。可保存全文PDF；仅有链接时，将链接记录在阅读卡中。

建议命名：作者_年份_题名简称.pdf、作者_年份_阅读卡.md。参考文献总表由D汇总，放入04_报告草稿。

## D的引用审查职责

D在最终审查中核对正文引用与参考文献是否对应、来源信息是否齐全。各文献提供者负责核实与修正自己的材料，D复核；参考文献总表和复核记录放入04_报告草稿。
