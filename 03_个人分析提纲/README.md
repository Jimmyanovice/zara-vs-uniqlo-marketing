# 个人分析提纲

本文件夹用于保存各成员基于文献和品牌证据形成的个人分析，供全组讨论并整合为报告。

| 对应角色 | 建议提交内容 |
| --- | --- |
| A | 竞争定位分析提纲、定位图草稿及坐标依据 |
| B | 营销策略分析提纲，重点比较2—3个策略差异 |
| C | 顾客参与分析提纲，区分参与机制和实际效果 |
| D | 竞争优势与问题分析、3个候选建议及建议对象选择 |

每份提纲请包含：

1. 3个初步判断。
2. 每个判断对应的两家品牌证据及来源。
3. 可以使用的理论和文献。
4. 局限、可能的反例和仍缺的资料。

建议命名：A_竞争定位提纲_日期.md，其他成员按相同方式命名，也可上传Word文件。原始证据放入02_品牌证据与截图，整合后的报告放入04_报告草稿。
